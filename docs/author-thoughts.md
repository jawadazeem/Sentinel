Recently, I realized that AVISOS might be aiming too low. It has the potential to be far more powerful. Currently, the system relies on a lightweight edge node that sends telemetry and images to a central server. This central server performs YOLO object detection and leverages an LLM with RAG to analyze the situation. This architecture is highly effective for processing-limited edge nodes, especially when conserving battery life in remote locations. For these use cases—like the Pavilion node, which uses a lightweight machine and a tiny camera—AVISOS works perfectly. It cannot process LLMs locally, but it efficiently streams periodic image data. Ideally, AVISOS should accommodate both these lightweight setups and more capable edge nodes that can translate visual data into natural language locally. These advanced nodes should independently compare current visuals against baseline expectations—detecting anomalies like an unexpected person or unauthorized movement. They can then transmit these natural language insights to the central controller. By synthesizing textual inputs from multiple edge nodes, the controller can construct a coherent situational narrative, update the frontend, and alert stakeholders via email.
